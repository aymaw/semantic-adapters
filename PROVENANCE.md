# Provenance

This is an original personal portfolio implementation created in November 2026
with AI-assisted development. It is a new engineering demonstration, not an
archive of historical research, employer code, or a deployed product.

All task data are generated by this repository from seeded random generators
and hand-authored fictional templates. No patient data, clinical recordings,
employer systems, proprietary models, or company configuration were used.
Library APIs and published methods are acknowledged in the README. External
pretrained weights, when used, retain their own upstream licenses; the MIT
license here covers this repository's original code and synthetic data.

Only executed runs belong in `results/`; generated checkpoints belong in
ignored `runs/`. Metrics describe this synthetic generator and do not establish
clinical performance, real-world language understanding, or production readiness.
