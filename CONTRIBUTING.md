# Contributing

Use Python 3.11–3.13. Install `pip install -e '.[dev]'`, run `ruff check .`,
`ruff format --check .`, and `pytest -q`. Keep changes small and include tests
for mathematical or state-transition behavior. Use entirely synthetic examples.
Do not submit patient records, transcripts, credentials, or proprietary source.
Document new runs with seed, command, versions, data hashes, and limitations.
